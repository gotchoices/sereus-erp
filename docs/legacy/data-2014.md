# ATI production data, 2014-01-03 (targeted extract)

The extract lives in `data/ati-2014/` at the project root. It is **local only and git-ignored**:
it is ATI data and schema, which stay out of the repository. This page records how it was
made, so it can be re-created on any machine that can reach the dump.

**Source:** `<archive>/ati/pgdata-2014-Jan-03.tgz` (16 GB compressed, June 2015), where
`<archive>` is the private archive the owner keeps it in. It is a per-table `pg_dump` of the
ATI production database at the end of its use. It was extracted on 2026-11-05 in one pass
(about 12 minutes over a network share). The command, run from
`data/ati-2014/` (create it first):

```
tar xvzf <archive>/ati/pgdata-2014-Jan-03.tgz \
  --exclude 'pgdata-2014-Jan-03/prd_doc_data.d' --exclude '*cdoc_data.d' \
  'pgdata-2014-Jan-03/*.s' 'pgdata-2014-Jan-03/*.c' \
  'pgdata-2014-Jan-03/prd_*.d' 'pgdata-2014-Jan-03/prod.*.d' 'pgdata-2014-Jan-03/mtr*.d' \
  'pgdata-2014-Jan-03/vend_price*.d' 'pgdata-2014-Jan-03/po_*.d' 'pgdata-2014-Jan-03/proj.d'
```

## Layout

Each table has three files:
* `<table>.s`: the schema (DDL, triggers, constraints)
* `<table>.c`: the row count
* `<table>.d`: the data (`COPY … FROM stdin`)

**All `.s` and `.c` files were extracted** (161 tables), so the schema catalog is complete.
**Data (`.d`) was extracted only for** the product (`prd_*`, `prod.*`), MTR (`mtr*`),
vendor-bid (`vend_price*`), PO (`po_*`) and project (`proj`) tables, about 584 MB in total,
most of it `mtr_reg.d` (517 MB).

Personal, payroll, contact, document-blob, GL and AP tables were deliberately **not** extracted.
If they're ever needed, they are still in the tarball. Note that `vend_org`, the vendor table,
is not extracted either, so vendor IDs in the bids can't be resolved to names or vendor types.

* `catalog.tsv`: every table with its row count, largest first.
* `extract.log`: the tar log.
